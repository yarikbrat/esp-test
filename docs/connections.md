# Фактическая схема стенда (как собрано сейчас)

Этот файл описывает **то, что физически подключено на макетке прямо сейчас**, а не то, что задумано.
Задуманная схема и объяснения: `docs/wiring.md`.

## Правила

1. После **каждого** изменения проводов этот файл обновляется: что подключили, куда, как проверили.
2. Провод считается подключённым правильно, только если это **проверено** прозвонкой по подписям выводов,
   а не по счёту, или работой устройства. Иначе в столбце «Проверено» стоит «нет».
3. **Перед каждой прошивкой ESP32** таблица «Выводы ESP32 в прошивке» сверяется с таблицей проводов.
   Если прошивка делает вывод **выходом**, а к нему подключено что-то, кроме того, чем он должен управлять, —
   не прошивать, пока не разберёмся.

Не подключено: модуль `DEF`, `LNK`, `LNK2`.

HC-SR04 (фото `docs/photos/2026-10-24-hc-sr04.jpg`): правая половинка, ножки в колонке `j`, ряды около 19–23,
датчик стоит вертикально, излучатели наружу. Точные ряды ножек: _уточнить_. Мультиметр 2026-10-24 не работал
(батарея), поэтому делитель проверен только работой датчика. Это не доказывает, что синий резистор не обойдён:
датчик работал бы и с 5 В на `D32`. **Когда будет батарея**, без питания проверить: `Echo` ↔ `D32` ≈ 1 кОм,
`D32` ↔ `GND` ≈ 2 кОм, `VIN` ↔ `GND` не звонится.

Резисторы для делителя `ECHO` (фото `docs/photos/2026-10-24-resistors.jpg`), измерены DT832 на пределе 20k
2026-10-24: синие (металлоплёночные, 5 полосок) — 1 кОм; бежевые — часть 2 кОм, часть 5.1 кОм.
Для делителя берём синий 1 кОм и бежевый 2 кОм. 5.1 кОм не используем.

Сетевой кабель: модуль ↔ разъём `Ethernet` ПК. USB: ESP32 ↔ ПК (в WSL BUSID `4-9`).

## Выводы ESP32 в прошивке

Прошивка сейчас: основная (`main/`), с 2026-10-24. Режимы выводов те же, что у тестовой.

| Вывод | Режим в прошивке | Что подключено по таблице проводов | Совпадает? |
|---|---|---|---|
| `D16` | вход UART2 RX | модуль `TXD` | да |
| `D17` | выход UART2 TX | модуль `RXD` | да |
| `D21`, `D22` | I2C0 | BMP585 | да |
| `D18`, `D19` | I2C1 | BMP581 | да |
| `D25` | вход с подтяжкой вверх (отпущено) | модуль `RST` | да |
| `D26` | вход с подтяжкой вверх (отпущено) | ничего | да |
| `D33` | **выход, держит 0** (`TRIG` дальномера) | HC-SR04 `Trig` | да |
| `D32` | вход с подтяжкой вниз (`ECHO`) | середина делителя от HC-SR04 `Echo` | да |

## История ошибок

- **2026-10-24.** Провод `DEF` модуля по ошибке стоял на `D33`, а не на `D26` (при счёте выводов сбились на два).
  Пока `D33` был входом, это ничему не мешало. Новая версия тестовой прошивки сделала `D33` выходом с 0 для
  дальномера, модуль увидел 0 на `DEF`, сбросился к заводским настройкам (192.168.1.254) и, пока 0 держался,
  не сохранял новые настройки. Провод снят, модуль перенастроен. Отсюда правила 2 и 3.
