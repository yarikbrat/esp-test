# Как подключиться к стенду с любого компьютера

У стенда нет DHCP: адрес задан статически и хранится в модуле UART TO ETH (B). По умолчанию
**192.168.144.36**, маска **255.255.255.0**, шлюза нет. Чтобы открыть стенд, компьютер должен быть в той же
подсети `192.168.144.x`. Интернет, роутер и сервер не нужны, хватит одного сетевого кабеля напрямую.

## 1. Подключение напрямую кабелем (обычный случай)

1. Сетевой кабель: модуль Ethernet стенда ↔ сетевой разъём компьютера. Если разъёма нет, подойдёт переходник
   USB–Ethernet.
2. Питание стенда: USB-кабель ESP32 в компьютер или в любой USB-блок питания.
3. Дать сетевому разъёму компьютера адрес из сети стенда, например **192.168.144.10**, маска **255.255.255.0**,
   шлюз пустой. Адрес не должен совпадать с адресом стенда.
4. Открыть в браузере **http://192.168.144.36/**.

### Windows 10/11 через настройки

Параметры → Сеть и Интернет → Ethernet → «Назначение IP-адреса» → «Изменить» → «Вручную» → включить IPv4:
IP-адрес `192.168.144.10`, длина префикса (или маска) `24` (`255.255.255.0`), шлюз и DNS оставить пустыми →
«Сохранить». Вернуть как было: там же выбрать «Автоматически (DHCP)».

Если интернет на этом компьютере идёт через тот же разъём Ethernet, на время работы со стендом он пропадёт.
Тогда интернет лучше брать по Wi-Fi, а стенд подключать к разъёму Ethernet или к переходнику USB–Ethernet.

### Windows из командной строки (от администратора)

Посмотреть имя подключения: `netsh interface ipv4 show interfaces` (обычно `Ethernet`).

```
netsh interface ipv4 set address name="Ethernet" source=static address=192.168.144.10 mask=255.255.255.0
```

Вернуть автоматическую настройку: `netsh interface ipv4 set address name="Ethernet" source=dhcp`.

На ПК разработчика разъёму `Ethernet` назначены сразу два адреса, 192.168.1.10 и 192.168.144.10: первый нужен,
чтобы видеть модуль с заводскими настройками (192.168.1.254). Как это сделано: `docs/hardware-log.md`.

### Linux и macOS

- Linux: `sudo ip addr add 192.168.144.10/24 dev <интерфейс>` (имя интерфейса: `ip link`).
- macOS: Системные настройки → Сеть → Ethernet → Подробнее → TCP/IP → «Вручную»: `192.168.144.10`,
  маска `255.255.255.0`.

## 2. Стенд должен жить в другой сети

Например, у заказчика сеть `10.1.2.0/24`, и стенд нужно включить в его коммутатор.

1. Подключиться к стенду напрямую, как в разделе 1.
2. На странице стенда в «Мережеві налаштування» ввести адрес из сети заказчика, например `10.1.2.50`, маску
   `255.255.255.0`, при необходимости шлюз. Нажать «Зберегти та застосувати».
3. Модуль сразу перейдёт на новый адрес. Компьютер из раздела 1 его больше не увидит: страница предупредит,
   что новый адрес не отвечает. Это нормально.
4. Включить стенд в сеть заказчика и открыть `http://10.1.2.50/` с любого компьютера этой сети.
   Первый же запрос по новому адресу ESP32 запишет новые настройки как рабочие.

Перед этим проверьте, что адрес свободен в сети заказчика: два устройства с одним адресом мешают друг другу.

## 3. Адрес стенда неизвестен или доступ потерян

### Найти модуль

- **VirCom** (программа производителя для Windows, установка не нужна): скачать
  https://files.waveshare.com/upload/4/42/VirCom_en.rar, распаковать, запустить `VirCom_en.exe`, нажать
  **Search**. Программа показывает найденные модули и их адреса. Проверено 2026-10-24: наш модуль VirCom находит
  (компьютер был в той же подсети). Находит ли она модуль, если компьютер в другой подсети, ещё не проверено.
- **Перебор адресов в известной сети** (Windows, обычная командная строка), если примерно известна сеть:

  ```
  for /L %i in (1,1,254) do @start /b ping -n 1 -w 300 192.168.144.%i >nul
  arp -a
  ```

  Модуль узнаётся по MAC-адресу, начинающемуся с `28-80-e4`.

### Вернуть адрес 192.168.144.36

1. Компьютер перевести в сеть найденного адреса модуля (раздел 1, только с адресом из той сети).
2. Открыть конфигуратор модуля: `http://<адрес модуля>:8000`, пароль пустой, «Login».
3. Поставить Device IP `192.168.144.36`, Subnet Mask `255.255.255.0`, Gateway `0.0.0.0`, остальное не трогать,
   «Submit». Модуль сразу перейдёт на новый адрес.
4. На ESP32 удерживать кнопку **BOOT** 5 секунд: ESP32 тоже вернёт у себя начальные настройки сети.

### Модуль сброшен к заводским настройкам

Если вывод `DEF` модуля замкнуть на `GND` дольше 1 с, модуль вернётся к заводскому адресу **192.168.1.254**,
порт данных 80, конфигуратор тоже на порту 80. Тогда:

1. Компьютеру дать адрес `192.168.1.10`, маска `255.255.255.0`, открыть `http://192.168.1.254`, пароль пустой.
2. **Первым шагом:** Device IP `192.168.144.36`, Device Port `4196`, Device Web Port `8000`, Gateway `0.0.0.0`,
   «Submit».
3. Компьютеру дать адрес `192.168.144.10`, открыть `http://192.168.144.36:8000`, войти.
4. **Вторым шагом:** Device Port `80`, «Submit».

Порт данных `80` нельзя ставить в той же форме, где конфигуратор переносится с порта `80`: модуль ответит
«Success!», но ничего не сохранит. Подробно: `docs/uart-to-eth-b.md`.
